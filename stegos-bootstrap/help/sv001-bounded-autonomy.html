StegVerse-001 bounded autonomy

This card checks the same-device history before exposing execution. Once the governed SV001 cycle reaches SV001_BOUNDED_AUTONOMY_CYCLE_COMPLETED, it is terminal for this cycle and should remain green on later visits.

Remediation

Do not rerun a completed cycle to recover a missing downstream receipt. If the card knows the cycle completed but the exact full proof predates persistent-card retention, use the Master Records manual import fallback for the immutable proof instead.
