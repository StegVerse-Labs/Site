Create a browser-local KnowledgeVault

This initializes KnowledgeVault data inside Safari's IndexedDB for this stegverse.org browser origin. It does not install a native app, filesystem service, background process, or OS-level resident vault.

Storage truth: browser IndexedDB is an origin-scoped data store. If Safari declines persistent-storage protection, the KV remains best-effort browser data and may be evicted. Exact readback proves only that the browser can read back the bytes written now; it is not evidence that software was installed.
