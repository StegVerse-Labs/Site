# SUBMISSION KIT — ECOSYSTEM KV SEAM (01)

Everything a submitter needs, in one file. Provided at the seam's
address (https://stegverse.org/kv-seam/) and filed at the seam as the
record copy. Canonical instruction: SUBMISSION__INSTRUCTION__02.

## The seam's address (paste this where a destination is asked)

StegVerse Ecosystem KV Seam — Node ECOSYSTEM-KV-SEAM
Public address: https://stegverse.org/kv-seam/
Your files stay in your storage. Submissions are manifests with
anchors (file locators + SHA-256 digests), never uploads.

## The 4 steps

1. ESTABLISH YOUR NODE — a first submission stating who you are and
   where, in your own storage, returns should be sent. Its response
   (SUCCESS, unless something is unsupported) equips you and confirms
   your node as healthy. Done once.
2. BUILD YOUR MANIFEST — fill in the scaffold below. The automated
   builder can draft it from your stated purpose; you confirm.
3. SUBMIT — send the manifest. The request itself is the work order,
   receipted start to finish: ingress, disposition, return egress.
4. RECEIVE THE GOVERNED RETURN — the results plus the complete
   receipt-chain segment of your submission, the receipt declared
   at the top.

## Manifest scaffold (complete every field)

SUBMITTER: <your identity>
RETURN ADDRESS: <in your own storage — where the return is sent>
PARTICIPATION CLASS: external / native (native = you have a
  registered healthy node)
FILES:
  - name: <file name>
    locator: <where it sits in your storage>
    sha256: <the file's SHA-256 digest>
PROTOCOL: <what you want done, precisely — e.g. "Govern this data
  packet against the constraints stated in it and return a JSON
  result", or "Evaluate this data set against <criterion>", naming
  the return form you want>
RETURN: <chat / file at the return address>

## The rules

No credentials — anything asking for one is not this seam. Custody
never moves: the original stays with you, a changed file is a
mismatch, not an arrival. Zero user data is collected; the seam
holds receipts, not submissions. A governed response, a HOLD, or
silence are the only outcomes; anything else is not from here.
