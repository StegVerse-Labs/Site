iPhone and browser guidance

Safari normally saves downloaded files through the Files app. Opera and some other browsers may keep downloads inside their own download manager. Before returning the package, explicitly save the PDF and JSON to Files so both can be selected together.

When the share sheet does not attach both files, open your email app manually, address the message to rigel@stegverse.org, use subject HIL Priority, and attach the verified PDF and package JSON from Files.

Fallback when file sharing is unavailable

Attach both unchanged files manually. Include the package ID and PDF SHA-256 in the message body. Do not paste, convert, or regenerate the PDF contents.
