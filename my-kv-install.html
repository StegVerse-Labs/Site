Install MyKV

MyKV is the single owner-facing installation surface. When you first launch the installed MyKV app, it automatically establishes or reuses the minimal resident StegOS/Node substrate required on this iPhone, runs the canonical resident-health diagnostic, and performs only bounded device-install repair when required.

This does not create, reinstall, replace, renumber, migrate, or rehost a KnowledgeVault. KV identity and storage location remain separate. Storage-host choices are presented only after the resident substrate is healthy.

1. Tap Safari's Share button.
2. Choose Add to Home Screen, then Add.
3. Open MyKV from the Home Screen. MyKV handles the resident StegOS/Node bootstrap automatically.

There is no separate StegOS website or second owner installation step. The resident StegOS/Node remains a device substrate underneath MyKV; MyKV remains distinct from the KV itself and from the owner-selected KV storage host.

Install MyKV, then launch it once to verify the resident substrate.
