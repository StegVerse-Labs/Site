Install MyKV

This installs the MyKV management surface on this iPhone. It does not create, reinstall, replace, renumber, or migrate a KnowledgeVault.

1. Tap Safari's Share button.
2. Choose Add to Home Screen, then Add.
3. Open MyKV from the Home Screen.

When launched from the Home Screen, this install shell opens the canonical MyKV page on the same StegVerse origin. The existing DEVICE_KV-first connection path remains responsible for detecting any resident KV.
